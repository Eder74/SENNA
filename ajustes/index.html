🔁
Envie a base completa no mesmo formato
Use quando a extração for refeita do zero. Tudo o que existe hoje deixa de valer e passa a valer só este arquivo; dá para desfazer excluindo a carga no histórico. As vendas mensais não mudam.
Formato do arquivo de lançamentos
Vale para adicionar lançamentos e para substituir a base. Os lançamentos do CD Cajamar entram com Num Loja = 2. Os nomes das colunas podem vir com ou sem acento e em qualquer ordem; a primeira linha com esses títulos é o cabeçalho. Linhas totalmente vazias são ignoradas. Linhas iguais não são erro: a baixa por lote de entrada gera linhas repetidas legítimas. Categoria e curva ABC não precisam vir no arquivo: são buscadas na base de produtos pelo código do item. O tipo de ajuste vem do código do motivo: PEIO/GAIO = I.O., PEIR/GAIR = Rotativo, os demais = Forms. Lógica 301 e 401 = perda; 302 e 402 = ganho.
