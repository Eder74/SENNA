Na lista, use Exportar → Exportar para CSV e envie o arquivo do jeito que sai, sem renomear colunas. Também aceita a mesma lista salva em Excel (.xlsx). Pode enviar vários arquivos de uma vez.
Cada chamado é identificado pelo ID: se o ID já existe, a linha nova substitui a antiga (status e classificação atualizados); se não existe, é adicionada. As cargas ficam na base compartilhada: todos que abrem o módulo veem os mesmos dados.
