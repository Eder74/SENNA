← S.E.N.N.A. - Central
Escolha os arquivos .senna.json que o Senna gerou (um por módulo). A importação substitui os dados do módulo: depois dela, a base fica exatamente igual à do arquivo. Cargas que não estão no arquivo são apagadas, para não somar em dobro. Os usuários e os acessos não são afetados. Esses arquivos têm dados da LDM: não suba no GitHub.
