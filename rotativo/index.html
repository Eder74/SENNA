Itens com maior divergência
Item que diverge em várias lojas aponta para cadastro, embalagem ou recebimento, e não só para a operação de uma loja. Clique num item para ver cada loja.
Quem contou
Pessoa que finalizou a contagem do item na lista (campo UPDATED_USER). Itens pendentes ficam com o usuário que criou a lista e não entram aqui.
Quem tratou as divergências
Encerrada sem 3ª contagem é a divergência fechada (SHUT_DOWN) sem recontagem; no cálculo ela conta como Não realizado · gestão.
Divergências no período
Data de referência: 3ª contagem; sem ela, a abertura da divergência. Vínculo mostra se a divergência foi ligada a um item de lista: no mesmo dia (como a planilha faz), em dia próximo (até 2 dias antes ou 10 depois) ou sem lista na base.

📤
Envie as extrações cruas, do jeito que saem do sistema
Aceita fato · produtos das listas, fato · divergências e também a própria planilha LDM_Rotativo (.xlsm), lendo as abas Listas_Contagem e Dados_Divergencias. O painel reconhece o tipo pelo cabeçalho, sem renomear colunas. Pode enviar vários arquivos de uma vez.
Cada linha é identificada pelo ID: se o ID já existe, a linha nova substitui a antiga (status atualizado); se não existe, é adicionada. Divergências repetidas no arquivo contam uma vez só. As cargas ficam na base compartilhada: todos que abrem o painel veem os mesmos dados.
